# 设计

策略持久化通过接口注入，原子快照沿用运行时策略服务。northstar 独立于 master，受静态总闸控制。后台沿用 leader 租约，按 UTC 小时原子删插，维护独立版本、水位和回填边界。D-1 的 24 小时替换在同一事务提交；接口只读汇总，不扫描用量原表。主键包含账号、客户端家族与协议，host 是聚合时快照。

金额在查询窗口按平台和模型计算分项均价，小时趋势共用窗口价格。列表、实扣和上游三个视角分别计算节省与机会金额；美元命中始终使用列表价差。业务范围用于金额权重及排名，严格范围用于北极星。隐私合并与 null 语义在后端统一计算。

trace 计数只在观测开启的请求中分配状态，在真实结算和事件输出后各计一次。关闭态不进入计数方法，日志与出站字节不变。接口 DTO 不用于用户侧，所有指标仅展示，不参与调度或自动调参。

图表标签按 P-3/R16 做隐私处理：邮箱形态的账号名输出为与 meta.platform/key 一致的平台及账号编号，分组名输出为 group#编号；普通名称保留，只改变响应，不改写原始或汇总数据。

R17：北极星 priced_models 为严格范围内有行的已定价 (platform, model_key) 数；单价与 priced_p_share 仍由业务范围计算，计数不随 cost_view 改变。
