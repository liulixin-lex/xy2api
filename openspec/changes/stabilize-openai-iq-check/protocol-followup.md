# OAuth 响应解析与诊断补充

## 本地改进范围

保持每轮独立请求、账号模型和深度配置、答案21标准及未知状态调度规则。兼容标准Responses SSE以及有限的媒体类型误标；辅助事件不强制解码为终态Response。只使用完成终态的最终assistant输出，禁止使用delta或推理文字判分。

HTTP错误、编码不支持、解压失败、非法JSON、重复关键字段、错误字段类型、冲突终态、流中断及超限分别记录原因。总解码正文256KiB、单事件128KiB、最多4096事件；诊断JSON数据库上限4KiB。HTTP传输已解压时沿用传输结果，插件返回未解压正文时支持gzip、deflate、br、zstd。

新增迁移242，在原两轮结果表增加可空diagnostic；旧记录保持可读，不增加独立历史表，不记录响应原文片段、推理或凭据。前端默认折叠诊断，失败原因优先显示。

## 验收

- 标准9事件SSE、CRLF、多行data、心跳、尾帧、缺失/误标媒体、压缩；有效21与29判分正确。
- 非法JSON、字段类型/重复字段、无终态、错误后置、重复一致/冲突终态、超时及大小上限保留未知。
- OAuth、Setup Token和API key Responses经过真实服务构造与模拟HTTP传输验证，终态覆盖增量内容，连续调用不携带历史。
- 诊断与记录同事务写入、仅留两轮、数据库拒绝超长对象；旧NULL诊断可读。
- 界面中英文、旧记录、异常值转义、键盘聚焦及390px布局。

## 证据边界

testdata/oauth-responses.sse是合成协议样本，不是生产捕获。先前只读检查证明主站0.0.9记录中OAuth返回invalid_response，尚未捕获失败事件。不能据此声称已经证明或解决主站全部根因。部署后应对已授权样本检查新诊断，再按具体原因修正；本轮不请求真实上游、不部署或发版。
