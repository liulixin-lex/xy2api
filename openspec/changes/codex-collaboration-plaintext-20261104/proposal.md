# Codex 协作消息明文通道与状态族观测

新增默认关闭的 P1′ 通道：对满足资格的原生 Responses HTTP 请求，原子改名协作命名空间并删除三个消息工具的加密声明，回程恢复规范身份，符合条件时补空 encrypted_function_args。API Key 与 OAuth 使用同一接线契约；预检仅覆盖三个 API Key 中转站及两个目标模型，OAuth 验证前不启用。

P0 在 v3 窄边界内统一状态族拒绝的识别与观测，终止换号和罚号，保持原有有限修复条件。P1′ 不解密、不修复已有历史，不扩展到 WS、透传、compact、桥接或摊平路径。2a/2b 预检、两路红队四轮复核、集成全量门禁与发版前真实端到端均已通过；灰度按部署 runbook 逐站开启，遵循同站账号一致及已用会话回退限制。
