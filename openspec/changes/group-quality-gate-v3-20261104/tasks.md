  - “无合格目标”占比只可按 `group_quality_gate.tier` 和 `openai_account_latency_hold_started` 事件离线近似；本批次没有直接计数，也不能由事件精确还原当时目标资格与空位。
- [ ] 6.3 7 天验收：以上一个版本的同时段表现为基线（用户 2026-11-04 确认），四个指标按 §11.2 口径比较：端到端首字 <10 秒占比降 >2 个百分点、缓存读取占比降 >1.5 个百分点、用户可见失败率升 >0.3 个百分点、记录内估计成本每百万提示 token 升 >3%；任一连续 2 天越线即回滚到上一个版本。单组问题可先在该组关闭 v3（立即生效）。发版前核对显示缓存与成本两条线在历史上常有同量级波动，判定时同时报告背景对照。
- [ ] 6.4 单项评估：P1-B 双门；判慢与新列只观测。
  - P1-B 再失败率：分母排除触发失败为会话状态族拒绝（S1–S4 及其他加密拒绝）的情况；分子保留下一次请求的全部失败。另报“改绑后下一次请求为状态族拒绝”的比例，与基线期对比。v3 期带密文片段的请求按连击规则处理，基线期无法识别这类请求，两期口径不完全对等，结论偏保守。
  - 同站暂停：
    - 关闭开关的条件：暂停期间其他站点的限流与过载率比紧邻等长时段上升 >1 个百分点，且本段 ≥5 次、两侧各 ≥200 次尝试；样本不足记“无法判定”。
    - 复核告警（不自动关闭）：平稳时段按暴露折算 >25 次账号暂停/24 小时。
    - 首次保护时间只报告“故障登记起点到首次事件”；满足触发条件却没有暂停事件时按实现或日志异常排查。触发条件本身不改。
