# OpenAI 智商检测

账号列表中，“调度”之后的蓝色开关启用糖果题检测。仅 OpenAI 账号可用；新建、复制和导入账号默认关闭。检测间隔为 1～1440 分钟，默认 15 分钟。

## 检测配置

编辑账号时，检测区域依次显示间隔、模型、思考深度。模型默认为 `gpt-6-astra`，思考深度默认为 `low`。可直接输入完整模型 ID，也可点击“拉取模型”，从该账号上游返回的目录中选择。请求使用输入的原始模型 ID，不经过账号模型映射，不自动换模型或重试。

目录读取不会修改账号白名单、分组、检测状态或模型元数据；OAuth 正常令牌刷新沿用现有流程。缓存有效期为 5 分钟，手动再次拉取刷新目录。失败时允许继续自定义；旧目录明确标记过期。目录中的模型来源与能力来源分开显示：上游仅返回 ID 时，不能推断它支持某种思考深度。Astra 的参考深度仅作参考，不代表该账号调用已验证。上游明确不支持的深度在表单阻止保存；能力未知时允许输入自定义值。

`upstream_default` 表示不发送思考深度参数；`none` 表示显式发送 `none`，两者不同。每轮记录任务领取时的模型、深度、协议和格式设置，另外展示上游报告的模型名称；项目无法验证第三方是否真正执行了所声明的模型。

默认兼容模式在两个协议中都请求简洁 `{"answer":整数}`。严格模式另外请求 JSON Schema：Responses 使用 `text.format`，Chat Completions 使用 `response_format.json_schema`。标准答案不写入提示或 Schema。上游不支持模型、参数或 Schema 时记为未知，不隐式回退；未遵循格式但答案明确时照常判分，并记录格式不合规。

批量编辑仅修改勾选字段，未勾选的字段保留各账号原值。只修改检测间隔不会重置智商状态或使正在执行的任务失效；修改模型、深度、输出约束、凭据、连接地址、协议、请求头或代理/TLS 配置时，检测重置为未知并重新排队。正常令牌轮换不使任务失效。复制和导入可以保留配置，但强制关闭检测、状态未知，不带历史和限制。

## 判定与恢复

每次会话独立，发送 `store:false`，不携带历史、会话 ID 或 `previous_response_id`。推理和 commentary 内容不参与判分。

| 完整最终回答 | 结果 |
| --- | --- |
| `{"answer":21}`、纯数字 `21`、明确结论为 21 的解释文字 | 聪明 |
| 明确最终答案为 29 或其他数值 | 降智 |
| 含糊、冲突、拒答、无法提取答案、重复 JSON 字段或无效结构 | 未知 |
| 网络、鉴权、额度、模型不支持、协议错误、响应不完整或超出限制 | 未知 |

数值按精确值比较，例如 `21.0000000000000001` 不等于 21。文本解析识别明确结论、更正、否定和反例；未识别到可靠最终答案时返回未知。它是这道糖果题的检测，不能由单题推出模型所有能力。

仅“开启且降智”阻止后续请求分配。聪明、未知或关闭检测都解除检测自身限制，不修改人工状态、调度开关或其他健康、过期及配额限制。**想继续使用被检测停用的账号，关闭该账号的蓝色智商检测开关**；原有规则允许时即可恢复。已开始的业务请求不被中断。

## 后台任务和记录

后台每 15 秒扫描一次，数据库租约保证各实例总计最多 10 轮检测并发。单轮超时 120 秒、租约 180 秒。降智账号继续检测。周期按完成时间加间隔，并加 0～`min(30秒,间隔×5%)` 的抖动；首次开启和手动运行不加抖动。失效的旧任务不能覆盖新配置；关闭后重新开启仍保留旧租约直到完成或过期，避免重叠检测。过期任务记为中断、状态未知，释放检测限制并通知调度缓存。

每账号最多保存两轮，包含运行中、失败、取消和中断轮次；第三轮开始时在同一事务删除最早一轮。记录展示提取答案、判定原因、实际模型/深度、协议、格式、版本及耗时，原始回答可展开。旧记录保留 `candy-grader-v1` 原义，不倒推或改写历史判分。新记录为 `candy-v2` / `candy-grader-v2`。

响应读取上限为 256 KiB，保存回答上限为 64 KiB；不保存凭据和推理内容，不在通用日志重复保存正文。删除账号清理记录。两轮清理仅保证本项目数据，`store:false` 不控制第三方自身保留政策。

## 管理员接口

- `PUT /api/v1/admin/accounts/:id/iq-check`：部分更新，例如 `{"model":"my-model","reasoning_effort":"upstream_default","output_mode":"compat"}`；省略字段保留原值。
- `GET /api/v1/admin/accounts/:id/iq-check/models?refresh=true`：只读上游目录，返回模型列表、能力来源、拉取时间、缓存/过期标志和错误代码。
- `POST /api/v1/admin/accounts/:id/iq-check/run`：立即排队；已有任务时复用，关闭检测时拒绝。
- `GET /api/v1/admin/accounts/:id/iq-check/results`：最近两轮记录。
- 创建、编辑及批量编辑支持 `iq_check` 部分设置；详情和精简列表返回摘要。
- 列表支持 `iq_status=smart|degraded|unknown`，在数据库分页前过滤；省略时为全部。
