## 备份和统计口径

生产只读目录/权限核查确认应用角色无法读取同库历史外部 schema；pg_dump/psql 18.6 与 PostgreSQL 18.4 兼容。未运行生产导出或恢复。使用者选择日常备份应用 public schema；新增显式范围并同时作用于手动/定时备份，旧设置仍按全库解释，旧客户端省略字段不会改掉已保存的范围。上线后在“系统设置 → 数据备份 → 备份策略”保存“应用数据（public schema）”。

导出错误保留有界脱敏原因；恢复强制 SQL 遇错失败和事务回滚，避免失败恢复误报成功。范围覆盖与独立演练见 [备份说明](BACKUP_RELIABILITY.md)。Redis、应用文件及密钥需要另行备份。

平均输出速率统一为输出 Token / 完整请求耗时，单位 tokens/s；缓存读取占比使用计费用量的非重叠三桶，不能据强制缓存计费推断真实供应商命中率。公式、缺失值与二开参考见 [统计口径](USAGE_METRICS.md)。
