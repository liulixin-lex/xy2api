## 已观察的根因与处理

| 领域 | 已观察的问题/根因 | 落实方向与验收 |
| --- | --- | --- |
| 取消 | 执行取消依赖 OnCancel 回调返回，阻塞回调可拖住明确停止 | 同步取消执行上下文，异步通知；验证原因与不可复活 |
| 终态 | 已收到 completed、下游仍背压时，取消覆盖真实完成结果 | 先确认终态，再交付终态帧；终态事件不可丢 |
| TTL | 幂等创建时间到期可以立即删除刚完成的响应 | 正文终态保留与幂等防重复期限分别执行 |
| 配额 | 日志降级后清理重复扣除，实测账面计数 -460 | 统一释放顺序，过期清理和旧 attachment 不能重复释放 |
| 规范化 | JSON 重复键在 gjson 与规范化解析中语义不同 | 所有层级拒绝歧义键，不能产生不同内容同幂等身份 |
| 热路径 | 每次 Snapshot 全量扫描全局留存 | 只检查本次 turn；保留容量/到期清理，单独报告微基准 |
| SSE 完整性 | EOF 人工补分隔符，把半个终态事件当完成 | 不合成终态边界，不交付截断帧 |
| Flush | Gin Flush 隐去底层 FlushError，网络失败被计作成功交付 | 解包透明 writer，检查实际 FlushError |
| 慢下游 | 原包装阻断 deadline，取消无法推进慢 TCP 写入 | 单 writer、每帧有界 Write+Flush、取消立即到 socket deadline |
| 多行事件 | 限制单行但不限制多行聚合，总内存可以无界 | 保留普通协议原限额，限制完整事件重组总量 |
| 内容计时 | custom tool 和图像 delta 漏分类；legacy created 停掉内容计时 | 语义仅用于观测/超时，created 不能代替首内容 |
| 真实终态 | Responses 的 [DONE]、incomplete/cancelled、bare error 收尾混淆 | 验证 Responses 终态，保留后续 failed 和 usage；Chat 保留其 [DONE] 语义 |
| JSON 与幂等 | HTTP 200 被当完成；错误正文幂等重放改成 200 | 依据原生 status 收尾，保留原始 HTTP 错误状态 |
| 控制权限 | retrieve/cancel 误用新生成计费准入，余额耗尽后无法停止/读取 | 精确路径免新生成余额/配额检查，继续校验主体、Key、组及当前权限 |
| 后台执行 | 非流式后台幂等未实现；queued 后轮询与 HTTP/调度收尾耦合 | 同原账号仅 GET 轮询、原执行额度移交、真正返回 HTTP、终态一次结算 |
| 页面诊断 | 请求切换后旧数据保留，迟到异步结果覆盖新请求 | scope watch、epoch 和 AbortController，卸载终止请求 |
| 验收门禁 | 补验的旧协议/真实存储用例未完全纳入强制 CI | 扩展精确 required，实跑空匹配/缺项/skip 拒绝守卫 |
| 后台额度 | queued/HTTP EOF、请求返回或 context 结束过早释放原 ticket 与账号/用户槽 | 将执行及额度移交独立 worker，保持原调度截止，真实终态或有界取消后释放 |
| 停机顺序 | 原异步执行未进入生产 cleanup 的有界等待 | 先关闭新准入并取消、等待原生 worker，再停止计费、传输和数据库 |
| 迟到确认 | 用户停止/停机之后才收到上游已接受后台任务的证明，原 ID 被拒收导致漏取消 | 只登记经过验证的原账号取消身份，不存正文、不改终态、不恢复执行 |
| 用量传递 | HTTP/WS 转换底层已解析失败/部分/取消终态 usage，上层包装仍返回 nil result | 保留已验证结果和原错误，并在真实最外层验证单终态、单次结算；原 16 例失败证据保留 |
| 旧读取兼容 | 新增后台意图判断直接对可空 dispatch.ctx 调 Value，旧 EOF 回归触发 panic | nil-safe 读取上下文，原测试保持不变；整树回归必须复验 |
| 后台协议路由 | 新增 HTTP→WS 路径复用了会移除 background 的 WS 消息构造器，显式后台请求实际被转换为前台 | 前台流才允许 WS 转换；显式后台保持 HTTP 原生语义，不虚构 WS 恢复能力 |
| 停机取消并发 | AfterFunc 已取得原生 cancel 所有权但 POST 尚在阻塞，worker 的重复取消提前返回，停机可先拆除上游传输 | cancelDone 完成屏障使 worker 等待有界取消结束；原失败反例与三轮真实 SSE 停机复验保留 |
| 迟到身份竞态 | 取消函数先读取 snapshot，随后迟到确认登记原账号/响应；BeginUpstreamCancel 成功后仍可能使用旧空身份 | 成功取得取消所有权后重新读取不可变原身份；JSON/SSE 迟到确认与停机三轮回归通过 |
| 性能分配 | 普通流终态修补重复 Marshal/Unmarshal/Marshal 大正文；完整六组先测 p95=12.722 ms，首次优化后仍为 10.008 ms | 保留三次正式失败；移除重复序列化、扫描与复制后，原六组 final04 通过（最差 p95=3.299 ms / p99=11.832 ms）；基准、阈值、样本与计时起点不变 |
| 基线探针 | 三态探针引用仅候选存在的 recorder helper，无法在原始源码独立编译（静态审查发现） | 改用同步探针自身足够的 httptest.NewRecorder；相同输入三态仍须实际执行 |
| 证据身份 | 原交付脚本只校验清单已有项，可遗漏门禁后的新增文件或 HEAD 漂移 | 对源码、tracked 文件、资产的完整集合及 HEAD/branch 做精确校验，失败不写成功 marker |
| 依赖安全 | 本轮新增实际 pnpm audit 检出 Axios 1.18.1 的七项未豁免 high 告警 | 最小升级到共同修复版本 1.20.0，保持其余传递依赖；高危审计及完整 2733 项前端测试/lint/build 已通过；未新增豁免，非当前可达的残余低/中危告警逐项留档 |

## 执行原则

每个已复现反例保留原始失败日志；修复后执行相同回归，再做跨模块验收。后台 HTTP 长连接复用阻塞以及提前释放调度额度属于上线阻断，不能靠关闭 keepalive、跳过测试或仅关闭开关掩盖。测试不得调用真实收费供应商。

最终仅在当前源码的功能、权限、取消、结算、并发、全量回归、性能、来源审计及三态事务完成后给出结论；远端推送限定审查分支，不包含合并、发布或生产部署。

## 已明确的能力边界

阶段 C 持久化、跨实例接管及进程崩溃恢复未实现；原生 WS 同响应续接和外部客户端/供应商恢复未认证，必须保持未确认或禁用。真实 Caddy 夹具验证代理压缩/缓冲，不替代完整网关或外部客户端认证。源码回滚只恢复离线 tar 副本，不是在线连接或数据库回滚。
